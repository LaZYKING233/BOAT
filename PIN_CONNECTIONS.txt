1. TB6612 电机驱动
------------------------------------------------------------------------------
  TB6612 引脚    STM32 引脚    CubeMX 功能         说明
  ----------    ----------    ---------------     --------------------------
  PWMA          PE9           TIM1_CH1 PWM        左电机 PWM (0~999)
  AIN1          PC8           GPIO_Output          左电机方向
  AIN2          PC9           GPIO_Output          左电机方向
  BIN1          PC10          GPIO_Output          右电机方向
  BIN2          PC11          GPIO_Output          右电机方向
  PWMB          PE11          TIM1_CH2 PWM        右电机 PWM (0~999)
  STBY          PD4           GPIO_Output (默认H)  TB6612 使能

  方向逻辑：AIN1=H, AIN2=L 正转；AIN1=L, AIN2=H 反转。BIN 同理。


2. LoRa 无线模块 (USART3)
------------------------------------------------------------------------------
  LoRa 引脚     STM32 引脚    CubeMX 功能         说明
  ----------    ----------    ---------------     --------------------------
  RXD           PB10          USART3_TX            STM32 发 -> LoRa 收
  TXD           PB11          USART3_RX            LoRa 发 -> STM32 收
  GND           GND           共地

  波特率：115200, 8N1, 无硬件流控
  中断优先级：0, 0 (最高)


3. GPS 模块 (UART4)
------------------------------------------------------------------------------
  GPS 引脚      STM32 引脚    CubeMX 功能         说明
  ----------    ----------    ---------------     --------------------------
  RXD           PA0           UART4_TX             STM32 发 -> GPS 收
  TXD           PA1           UART4_RX             GPS 发 -> STM32 收
  GND           GND           共地

  波特率：38400, 8N1
  模块：ATK-MO1218 / ATK-1218-BD 默认波特率


4. IMU901 陀螺仪 (USART2)
------------------------------------------------------------------------------
  IMU 引脚      STM32 引脚    CubeMX 功能         说明
  ----------    ----------    ---------------     --------------------------
  RXD           PA2           USART2_TX            STM32 发 -> IMU 收
  TXD           PA3           USART2_RX            IMU 发 -> STM32 收
  GND           GND           共地

  波特率：115200, 8N1
  模块：正点原子 ATK-IMU901, ATKP 协议


5. pH 传感器 (ADC)
------------------------------------------------------------------------------
  pH 模块引脚   STM32 引脚    CubeMX 功能         说明
  ----------    ----------    ---------------     --------------------------
  AOUT          PC0           ADC1_IN1             模拟输入

  PCB 新版直连 ADC（不分压）
  ADC 配置：14bit, 3.3V 参考, 采样时间 391.5 周期

6. 浊度传感器 (ADC + GPIO)
------------------------------------------------------------------------------
  浊度模块引脚  STM32 引脚    CubeMX 功能         说明
  ----------    ----------    ---------------     --------------------------
  AOUT          PC1           ADC1_IN2             模拟输入
  DOUT          PB0           GPIO_Input (Pull-up) 数字输出 (高/低浊度阈值)

  PCB 新版 2/3 分压（ADC = 传感器输出 × 2/3）
  ADC 配置：14bit, 3.3V 参考, 采样时间 391.5 周期


7. DS18B20 温度传感器 (GPIO)
------------------------------------------------------------------------------
  DS18B20 引脚  STM32 引脚    CubeMX 功能         说明
  ----------    ----------    ---------------     --------------------------
  DQ            PB1           GPIO_Output          单总线数据
  VDD           3.3V                               供电
  GND           GND                                共地

  需要 4.7k 上拉电阻 (DQ -> 3.3V)
  推荐三线制：VDD / DQ / GND

==============================================================================
  快速查阅版
==============================================================================

  电机驱动 (TB6612)
    PE9  <- TIM1_CH1 PWM (左电机)
    PE11 <- TIM1_CH2 PWM (右电机)
    PC8  <- 左电机方向 AIN1
    PC9  <- 左电机方向 AIN2
    PC10 <- 右电机方向 BIN1
    PC11 <- 右电机方向 BIN2
    PD4  <- TB6612 STBY (默认高)

  LoRa (USART3)
    PB10 -> USART3_TX (发)
    PB11 <- USART3_RX (收)

  GPS (UART4)
    PA0  -> UART4_TX (发)
    PA1  <- UART4_RX (收)

  IMU901 (USART2)
    PA2  -> USART2_TX (发)
    PA3  <- USART2_RX (收)

  pH 传感器
    PC0  <- ADC1_IN1 (模拟)

  浊度传感器
    PC1  <- ADC1_IN2 (模拟)
    PB0  <- GPIO_Input (数字)

  DS18B20 温度
    PB1  <-> GPIO (单总线, 需4.7k上拉)

  调试
    PA13 <- SWDIO
    PA14 <- SWCLK


==============================================================================
  注意事项
==============================================================================

  1. 所有模块共地 (GND)
  2. pH 传感器 PCB 新版直连 ADC（不分压）；浊度传感器 PCB 新版 2/3 分压（ADC=传感器×2/3）
  3. DS18B20 数据线必须接 4.7k 上拉电阻到 3.3V
  4. GPS 室内测试 fix=0, sat=0 是正常现象
  5. IMU 使用 USART2 115200，验证时观察 ib/ia/iv 字段
  6. LoRa 使用 USART3 115200，中断优先级最高
  7. 如更换分压比例，需同步修改代码中的分压相关宏定义
  8. CubeMX 工程：BOAT.ioc
  9. Keil 工程：MDK-ARM/BOAT.uvprojx
