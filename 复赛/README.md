# 复赛路演版本说明

本版本采用 GPS + IMU 闭环导航。原 GPS 失效时使用的浏览器定位、陀螺仪北向标定和定时直行开环方案已退出正式路演链路。

## 启动

双击 `run-webui.bat`，或进入 `复赛/webui` 后运行 `npm start`，浏览器访问 `http://localhost:3000`。

## 路演主流程

1. 连接 LoRa USB 串口，确认页面显示串口已连接。
2. 将船放到室外开阔水面，等待 GPS `fix > 0`，并确认 IMU 航向数据有效。
3. 在地图或养殖区域中选择目标区域并下发任务。
4. WebUI 将目标点、到达半径、漂移归位半径和区域矩形边界一并发送给 STM32。
5. 船按 GPS 位置和 IMU 绝对航向闭环前往目标；航行中会修正横向偏差。
6. 到达后进入区域保持；漂移超过阈值会自动回到目标点，越出区域边界会优先返回区域中心。
7. 到点稳定后按任务配置采集 pH、水温和浊度，并通过 LoRa 回传到 WebUI。

## 安全行为

- GPS 未定位或航行中丢失定位时，固件立即停止电机并进入 `GPS丢失` 状态。
- GPS 恢复后，固件重新建立当前航段并继续 GPS 导航。
- 超出区域矩形边界和容差范围时，固件进入 `越界归位`，返回区域中心后恢复原任务。
- WebUI 可随时发送停止命令，也可在高级模式下直接测试电机和调整左右电机校准参数。

## 新增遥测

- `bs` / `bd`：边界状态、距边界距离。
- `rs` / `rd`：越界归位状态、距归位点距离。
- `xt`：航线横向偏差。
- `ch`：横向修正后的目标航向。

## 关键文件

- `../Core/Src/main.c`：遥测、LoRa 命令分派和主循环。
- `../Hardware/GPS.c`：NMEA 定位数据解析。
- `../Hardware/IMU901.c`：绝对航向数据。
- `../Hardware/Navigation.c`：GPS 导航、横向偏差修正、区域保持和越界归位。
- `../Hardware/Lora.c`：任务参数和控制命令解析。
- `webui/server.js`：串口、任务状态机、采样、区域边界参数和本地 API。

## 上场前必须实测

- GPS 在路演场地能稳定定位，`fix`、卫星数和经纬度持续更新。
- IMU 航向与正北方向一致，电机工作时没有严重磁干扰。
- 左右电机方向和校准值正确，航向 PID 与横向修正参数不会引起振荡。
- 实际区域中心、长宽、到达半径、漂移半径和边界容差符合场地尺寸。
- pH、浊度和水温传感器已经用实物或标准液完成校准。
