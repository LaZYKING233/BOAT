# 网络串口中继（tools/relay）

把 USB 设备（LoRa 接收器）挂在一台"中继盒子"上，
**WebUI、计算、记录、图表全部仍然跑在主力电脑上**。

    ┌──────────┐  USB   ┌──────────────────┐   TCP    ┌────────────────────┐
    │ LoRa 接收 │ ─────▶ │ 中继盒子          │ ───────▶ │ 主力电脑            │
    │ (CH340)  │        │ serial-bridge.js │          │ WebUI + boatctl     │
    └──────────┘        └──────────────────┘          └────────────────────┘
                              只转发字节                所有计算都在这里

盒子不跑网页、不存数据、不做任何计算，只把串口字节原样转发到 TCP。
实测额外开销可以忽略，一个树莓派/旧笔记本/任何能跑 Node 的机器都够用。

---

## 一、中继盒子上要做什么

### 1. 装 Node

到 https://nodejs.org 装 LTS 版即可，不需要其他东西。

### 2. 拿到代码

两种都行：

- 盒子能上网：`git clone https://github.com/LaZYKING233/BOAT.git`
- 不能上网：只拷 `tools/relay/` 和 `WebUI/node_modules/serialport` 两个目录

### 3. 启动

```bash
cd BOAT/tools/relay
node serial-bridge.js --port COM6
```

可选参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `--port` | COM6 | 盒子上的串口名 |
| `--baud` | 115200 | 波特率 |
| `--listen` | 4001 | 监听端口 |
| `--host` | 0.0.0.0 | 允许外部连 |

启动后会打印出可以用的地址：

```
  在这台电脑上把 WebUI 的串口地址填成：
    tcp://192.168.8.111:4001
    tcp://100.89.233.10:4001
```

串口掉了会自动重连（每 3 秒），不需要人工干预。

---

## 二、主力电脑上怎么做

WebUI 的串口地址填成 `tcp://<盒子IP>:4001` 即可，其余操作完全一样。

**注意**：本机上的 COM 口列表里不会出现这个地址，需要手动填。
如果界面上暂时没有输入框，可以直接调接口：

```powershell
Invoke-WebRequest -Uri 'http://127.0.0.1:3000/api/serial/open' -Method POST `
  -Body '{"path":"tcp://192.168.8.111:4001","baudRate":115200}' `
  -ContentType 'application/json'
```

断开用 `POST /api/serial/close`。

命令行工具（boatctl）不用改，它只跟 WebUI 的 HTTP 接口打交道。

## 三、网络怎么通

三种情况：

| 场景 | 做法 |
|---|---|
| 同一个 WiFi / 手机热点 | 直接用盒子的局域网 IP |
| 两台机器不在同一网络 | 都装 **Tailscale**，用 100.x 地址（队友那套 `tools/migrate/ssh/` 已经装好了） |
| 完全没网 | 不行，中继必须能通到主力电脑 |

Tailscale 的好处：地址固定，换网络也不用改配置。

## 五、烧录怎么办

中继只解决**通信**，不解决**烧录**。

ST-Link 有两种放法：

- **放主力电脑上**：更新固件时把船拿回来插一下，平时拔掉
- **放盒子上**：盒子上要有 STM32CubeProgrammer，用 `firmware/*.bin` 烧（`0x08000000`）

调试阶段建议 ST-Link 留在主力电脑上——烧录不频繁，而链路是持续需要的。
