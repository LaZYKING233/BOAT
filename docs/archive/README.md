## 注意

`plans/` 和 `memory/` 里描述的若干方案已经被否决或反向修改，**不要照着做**：

- `plans/*.md` 里的"浏览器定位冒充 GPS""浊度写死 3 NTU""定时器模拟采样"等做法，
  在后来的"诚实化"重写中被全部删除。现在的系统只呈现真实串口数据。
- `memory/*.md` 里提到的 Keil / MDK-ARM 构建流程已经废弃，现用 STM32CubeIDE。
- `memory/*.md` 里关于浊度传感器的部分已作废——该传感器已停用。

当前有效的说明以仓库根目录 `README.md` 和 `docs/BRINGUP.md` 为准。
