# 硬件上板联调手册

> 面向"从零到能拍演示视频"的最短路径。每一步都给出**可判定的通过标准**，
> 不要跳步——上一级没通过时，下一级的现象没有诊断价值。

## 当前硬件范围

| 模块 | 接口 | 状态 |
|---|---|---|
| pH | PC0 / ADC1_IN1 | 使用 |
| DS18B20 水温 | PB1 单总线 | 使用 |
| GPS ATK-MO1218 | PA0/PA1 UART4 @38400 | 使用（室外才定位） |

## 第 0 步：确认能收到数据

LoRa USB 接收端插电脑，用 `后端/2.py` 以 115200 打开对应 COM 口。

**通过标准**：上电 1 秒内看到 `{"t":"boot",...}`，随后每秒一条 `{"t":"data",...}`。

完全没数据：查 PB10/PB11 是否接反、是否共地、波特率是否 115200。
**不要往下走**，后面所有现象都会被这一层掩盖。

---

## 第 1 步：主循环节奏

`data` 里的 `ms` 是 `HAL_GetTick()`，连续两条的差值应 ≈ 1000。

**通过标准**：差值稳定在 1000±50。

> 本次修复的关键：旧 DS18B20 实现每秒阻塞 750ms，把 `Navigation_Update()`
> 从 50ms 拖到 ~1.2Hz，PID 无法收敛。现在是状态机，单次循环约 2ms。

---

## 第 2 步：pH

**通过标准**：`phr` 有稳定读数（空气中约 8000-9000），`phmv` ≈ `phr` × 3300 / 16383。

`ph` 是估算值，未标定前不要相信。用白醋（≈pH 3）和小苏打水（≈pH 8）各测一次，
得到两个 (mv, pH) 点后重算 `Telemetry_CalcPhX100()` 的斜率与截距。

---

## 第 3 步：水温

**通过标准**：`tv=1` 且 `tc` ≈ 室温×100，手捏探头会缓慢上升。

`tv=0` 排查顺序：
1. PB1 是否真接到 DQ（不是 3.3V/GND）
2. 4.7k 上拉是否焊好（DQ → 3.3V）
3. 是否三线制且 VDD 已供电（寄生供电模式未启用）
4. 换一个探头交叉验证焊点

固件已过滤上电默认值 `0x0550`，**不会再出现 85℃ 假值**，读不到就是 `tv=0`。

---

## 第 4 步：IMU 航向

**通过标准**：`iv=1`，`ib` 与 `ia` 持续增长，`iy` 随手转船体而变化。

`ib` 涨但 `ia` 不涨 → ATKP 帧校验不过，查 USART2 波特率。
`iy` 转 360° 后回不到原值 → 磁干扰或零漂，见第 7 步。

---

## 第 5 步：GPS（必须室外）

**通过标准**：室外 1-2 分钟内 `fix>=1`、`sat>0`、`lat`/`lon` 量级合理。

`gb`/`gl` 涨但 `fix` 恒为 0 → 信号问题，换开阔地。

---

## 第 6 步：电机（先架空，不要上船）

WebUI「船体控制」，或 `2.py` 直接发：

```json
{"t":"motor","l":50,"r":0}
{"t":"motor","l":0,"r":50}
{"t":"cmd","cmd":"stop"}
```

**通过标准**：`l:50,r:0` 只有左桨转且朝前；`l:0,r:50` 只有右桨转且朝前。

一正一反说明该侧 AIN1/AIN2 接反——**改线，不要改代码**。
某侧完全不转：查 H 桥 VM 供电、STBY(PD4) 是否为高、该路 PWM 是否有输出。

---

## 第 7 步：零漂

船静置水面读 `iy`，记录 60 秒漂移量。漂移 > 2°/分钟时航向闭环会持续跑偏，
停机重新上电让模块重新初始化陀螺零偏。

---

## 第 8 步：导航闭环

先在 WebUI 把任务参数改成**演示尺度**再测：

| 参数 | 默认 | 演示建议 |
|---|---|---|
| 采样持续（分钟） | 60 | **0.5** |
| 稳定等待（秒） | 30 | 10 |
| 采样间隔（秒） | 5 | 2 |
| 中心到达半径（m） | 1 | 2 |
| 保持/兜底半径（m） | 5 | 6 |
| 边界容差（m） | 2 | 6 |

> 默认是"每点采 1 小时"，8 个点 = 8 小时，不改永远走不完一轮。

然后地图点区域 → 发送目标。

**通过标准**：
1. `ns` 0→1，`nd` 随时间下降
2. 船头朝目标，`nt` 收敛到 ±10° 内
3. 进入半径后 `ns`→2（区域保持），电机停
4. 8 点走完，任务完成

**调参**（都在 `Hardware/Navigation.c` 的 `Navigation_Init()`）：

| 症状 | 动作 |
|---|---|
| 原地打转 | `heading_pid.kp` 2.0 → 0.8 |
| 走 S 形 | `heading_pid.kd` 1.0 → 0.3 |
| 长期偏离航线 | `crosstrack_pid.kp` 0.8 → 0.3 |

## 现象对照表

| 现象 | 最可能的原因 |
|---|---|
| 完全没有 data 报文 | LoRa 接线 / 波特率 / 未上电 |
| `ms` 间隔远大于 1000 | 主循环阻塞（本次已修 DS18B20） |
| JSON 被截断 | 单行过长，检查 `lora_tx_buffer` 余量 |
| `tv=0` | DS18B20 接线 / 上拉 / 探头 |
| `iv=0` | IMU901 未接或 USART2 波特率不对 |
| `fix=0`（室内） | 正常，去室外 |
| 一个电机转一个不转 | 该侧 H 桥方向脚 / 供电 |
| 船原地打转 | `heading_pid.kp` 太大 |
| 到点后反复"越界归位" | 采样点在区域边界上 + 边界容差太小，调大 `bm` |
